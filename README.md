# 📝 Notes App

A simple and modern Notes App built using **Jetpack Compose** and **Kotlin** following the **MVVM (Model-View-ViewModel)** architecture. This application allows users to add and delete notes with a clean Material 3 user interface.

## 🚀 Features

- Add new notes using an AlertDialog
- View notes in a scrollable list
- Delete notes instantly
- In-memory data storage
- Material 3 UI Design
- Single Activity Architecture
- MVVM Architecture
- Built entirely with Jetpack Compose

## 🛠️ Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- MVVM Architecture
- ViewModel
- LazyColumn
- Scaffold
- FloatingActionButton
- AlertDialog

## ▶️ How to Run

1. Clone the repository.
2. Open the project in Android Studio.
3. Sync Gradle dependencies.
4. Run the application on an Android Emulator or physical device.
